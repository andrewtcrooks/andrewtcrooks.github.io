What we do

  • Local language models. Speech-to-text, embedding and text-generation models deployed on laptops, workstations and small servers, running with no network connection.
  • Document ingestion and retrieval. Scanned and digital records captured, text extracted, indexed for full-text and meaning-based search, and answered against with citations back to the source page.
  • Workflow automation and integration. Python, REST APIs and scheduled jobs that move data between existing systems and end manual re-entry.
  • Self-hosted infrastructure. Linux, Docker, PostgreSQL, vector databases, monitoring, backups and secure remote access.
  • AI agent systems with controls. Model routing, usage limits, audit logging, long-term memory and human approval before anything leaves the system.

Systems we built and operate

We are a young firm without government past performance. Each system below was designed and built by DataNova and is in use today.

Therapize: language models on a laptop, offline. A desktop application for therapists that records a session, transcribes the audio and writes structured clinical notes. Transcription and note generation both run on models installed on the user's own computer. No audio or text leaves the device, and the application works with no network connection.

Private document pipeline. Automatic intake of scanned and digital documents, text extraction, classification, extraction of dates, parties and key facts, and question answering over the full set using vector search. The document store and search index run on private infrastructure. Text-extraction and language models are chosen per deployment, including fully local models where data cannot leave the network.

Rook CEO: an AI operations platform. Software agents that run scheduled research, qualification and reporting tasks for a working business, with routing between local and commercial models, per-task usage limits, a budget guard, an external long-term memory service, and human approval on every outbound action.

Self-hosted operations. More than 50 monitored services (ERP, mail, workflow automation, analytics, vector database) with backups and secure remote access, running DataNova's own business.

How we work

Data stays where it is. We design for open-source, self-hosted components first, so a deployment adds no new cloud vendor unless the customer chooses one.

Small first milestones. Written scope and price agreed up front, with a working system at the end of each milestone.

One accountable owner. The person who scopes the work builds it and answers for it.

Teaming. We subcontract to primes and team with other small businesses on larger efforts.
