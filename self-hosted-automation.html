Questions

Why self-host instead of n8n Cloud or Zapier?

No per-execution fees, your data stays on infrastructure you control, and you can run as many workflows as the server handles. Cloud plans are a fine choice too; we'll tell you honestly which fits.

What server do we need?

A small VPS (typically $10–30 a month) or a machine you already own is enough for most small businesses. We help you choose and set it up.
