Questions

Where does our data go?

It stays on your server or private cloud. By default nothing is sent to a third-party AI service; if a cloud model would help, we discuss it with you first and it is your choice.

What kinds of documents work?

Scanned paper, PDFs, images, email attachments and office files. Handwriting and poor scans work less well; we test your real samples before committing to the pilot.

Have you built this before?

Yes. See the document intelligence case study: we run the same approach on a private document set today.

Do we need our own server?

A small server or private cloud instance is enough for most pilots. If you don't have one, we set it up as part of the work and you own it.
